AI / ML · Backend 06

Predictive Network Traffic Management

Congestion forecast → reroute before the link saturates

An SDN control plane that reroutes before a link saturates rather than after. Random Forest, XGBoost, LSTM and GRU models forecast per-link congestion from collected flow statistics; when a forecast crosses the threshold the controller recomputes a weighted shortest path and moves the flows. A Next.js dashboard streams the topology and the predictions over WebSocket.
